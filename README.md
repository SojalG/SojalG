Full-stack platform built for APAC-region disaster readiness — React/Vite frontend, Express/Node backend, Flask ML microservice, MongoDB Atlas. Deployed on Railway.
`React` `Vite` `Node.js` `Express` `Flask` `MongoDB` `Railway`

#### 💻 [CompileIN](https://github.com/SojalG/CompileIN) — AI-Assisted Web Compiler
A full-stack web compiler with an AI-assisted, real-time coding and learning experience — responsive UI, scalable backend, seamless compilation workflows.
`React` `Tailwind` `Node.js` `Express` `MongoDB`

#### 🤟 [SignBridgeAI](https://github.com/SojalG/SignBridge-AI) — Sign Language to Speech Translator *(Ongoing)*
Real-time deep learning pipeline that turns sign gestures into structured, spoken output — CNNs, landmark tracking, and continuous sequence modeling for natural sign-to-sentence conversion.
`TensorFlow` `MediaPipe` `OpenCV` `NLP`

#### 📞 AI for Call Assistant *(Ongoing)*
An intelligent voice assistant that extracts intent straight from speech — no keypads — using generative AI, NLP, and real-time speech-to-text/text-to-speech.
`GenAI` `NLTK` `spaCy` `Whisper AI` `pyttsx3`

#### 🚁 Mini Drone for Disaster Management
Led a 5-member team building an Arduino Nano-powered drone with GPS, gyroscope, barometer, and thermal camera integration for emergency navigation and environmental monitoring.
`Arduino Nano` `GPS` `NRF24` `Hardware Integration`
